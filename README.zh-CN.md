## 📂 已收录资源

本仓库收录的“开源卫星资源”，是指可公开分享的知识和参考资料，而不是卫星软件源代码或卫星数据集。收录内容包括研究报告、行业标准、技术规范、工程指南和科普材料，用于帮助社区理解、设计、评估或讨论卫星系统。

## 计划收录的资源范围

后续新增内容将继续限定在非代码、非数据范围内，计划收录以下几类资料：

- **标准与规范：** 与卫星系统、星载计算、通信及相关工程活动有关，且可公开分享的标准、建议、接口规范和术语文件。
- **研究报告与白皮书：** 研究机构、产业界或开源社区发布的卫星技术、系统架构、工程实践或标准化进展分析报告。
- **工程指南：** 面向卫星相关系统的验证与测试、可靠性、安全、安保、质量保证、鉴定和认证等实践文件。
- **科普与参考材料：** 帮助学生、研究人员和工程师理解卫星技术及其标准的入门说明、术语表、综述和其他参考资料。
